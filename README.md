# 币安建仓实时监控（公开页）

[English](README_EN.md) | 中文

王建中原创的币安合约持仓监控页。本地桌面版「币安建仓」原样部署到 GitHub Pages，方便随时查看主账户、子账户的持仓、盈亏和对照走势。

**在线地址：** [https://jianzhongwangace.github.io/binance-jiancang-public/](https://jianzhongwangace.github.io/binance-jiancang-public/)

## 功能

- **账户汇总**：钱包余额、保证金、未实现盈亏、可用、权益、累计手续费与资金费，并按美元兑人民币汇率换算。
- **一行三列**：每个产品一行，左边是币安持仓卡，中间是加仓试算，右边是对应美股卡。
- **持仓卡**：持仓数量、均价、现价、杠杆、保证金、爆仓价、已实现盈亏等；各字段按实际更新时间标注「x秒前刷新」。
- **走势图**：币安卡默认 15 分钟 K 线，5 分钟周期为折线图；美股卡默认周线。图中建仓价、现价、爆仓价三条线按真实价格完整显示，价格轴会把这三条线都包进来。
- **加仓试算**：可输入额外加仓金额或新增保证金（两者可互推），计算综合新建仓价格、按杠杆需新增的保证金、维持现有爆仓线还需加入的保证金、一共需要的保证金、加仓前后真实杠杆率，以及追加后的爆仓价。金额后附人民币。
- **美股对照**：展示对应标的的行情（含盘前等信息），方便和币安持仓对照。

本页只做展示和试算，不会下单。

## 仓库里有什么

| 文件 | 说明 |
| --- | --- |
| `index.html`、`实时价格监控_WebSocket版.html` | 监控页（两份内容保持一致） |
| `positions_live.js` / `.json`、`subaccount_live.js` / `.json` | 主账户、子账户的实时持仓快照 |
| `vendor/` | 页面用到的图表库 |
| `sync_positions.ps1`、`sync_subaccount.ps1`、`publish_live_to_github.ps1` | 在本地拉取持仓并发布快照的脚本 |

持仓数据由本地电脑定时同步到本仓库，公开页自动更新。请不要把 API Key、密钥或 `.env` 文件提交进来。

## 本地查看

把本仓库克隆或复制到电脑后，用浏览器打开 `index.html` 即可。公开页与本地页是同一套界面。
